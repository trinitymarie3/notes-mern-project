# MERN Note-Taking App

This is a full-stack note-taking application built using the MERN stack (MongoDB, Express, React, Node.js). The project is currently in development.

The backend API is completed and supports note management, while the frontend is actively being developed.

## Features

- RESTful API for managing notes
- Create, read, update, and delete notes (CRUD)
- Backend built with Express and MongoDB
- Frontend in progress (React + Vite + Tailwind + daisyUI)

## Tech Stack

- MongoDB
- Express.js
- React.js (in progress)
- Node.js
- Tailwind CSS + daisyUI

## API

Endpoints:

- GET /api/notes
- POST /api/notes
- PUT /api/notes/:id
- DELETE /api/notes/:id

## Status

- Frontend currently under development
- Backend API completed

This project is actively being improved with new features and UI enhancements.
